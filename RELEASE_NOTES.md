# Langue 1.1.0 — version de test

**Cette APK est une version de test pour les essais personnels. Elle utilise une signature de développement et n’est pas une version de production.**

Langue est une application Android gratuite d’apprentissage des langues. Elle fonctionne sans Internet, sans compte et sans publicité. Des packs permettent de choisir les langues à apprendre.

## Ce que vous pouvez essayer

- Le vocabulaire organisé en catégories et la recherche de traductions.
- Les exercices et quiz, avec suivi de la progression.
- La prononciation audio lorsqu’elle est fournie dans le pack.
- L’importation de packs et la sauvegarde de la progression.

**Aucune leçon ni aucun vocabulaire n’est préinstallé.** Pour commencer, importez votre pack dans **Paramètres → Importer un pack**.

## Installation

Android 8 ou supérieur est nécessaire. Téléchargez `langue.apk` sur votre téléphone, ouvrez le fichier et autorisez son installation si Android le demande.

## Avant une mise à jour

Une version signée avec une autre clé peut être refusée par Android. Les compilations de test provenant de machines différentes peuvent utiliser des clés différentes. Ne désinstallez pas votre application sans avoir exporté votre progression et conservé vos packs : la désinstallation efface les données locales.

Une future version de production devra utiliser une clé de signature durable sous le contrôle du propriétaire du projet.
