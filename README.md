# Langue

Une application Android gratuite pour apprendre du vocabulaire, entièrement hors ligne. Sa base universelle accueille vos propres packs de langues. Interface en français, sans compte ni abonnement. Compatible avec Android 8.0 et les versions suivantes.

## Installer l’application

Lorsque l’APK sera publié :

1. Téléchargez le fichier `langue.apk` sur votre téléphone Android.
2. Ouvrez le fichier téléchargé.
3. Autorisez l’installation depuis cette source si Android vous le demande, puis terminez l’installation.

## Ce que vous pouvez faire

- Parcourir le vocabulaire par catégories.
- Rechercher un mot ou sa traduction.
- Vous entraîner avec des exercices et des quiz.
- Écouter les enregistrements audio inclus dans vos packs.
- Suivre votre progression et sauvegarder vos résultats.
- Utiliser l’application sans connexion Internet.
- Ajouter de nouvelles langues en important des packs.

## Ajouter votre contenu

**Aucun cours, vocabulaire ni pack de langues n’est préinstallé.**

Ouvrez **Paramètres → Importer un pack**, puis choisissez votre pack de langues au format ZIP. Les onglets **Vocabulaire**, **Quiz** et **Paramètres** vous permettent ensuite de consulter le contenu et de vous entraîner. Les enregistrements audio sont facultatifs.
